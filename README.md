## Game Description

A 2D Unity game in which the player controls a white capsule using WASD and collects randomly generated coins while avoiding a red enemy that continuously chases the player.

## Coin Types

- Orange Coin – 50 points
- Green Coin – 20 points
- Blue Coin – 10 points

Five coins are generated at a time. A new batch appears after all five coins have been collected, provided the player has not yet won.

## Game Rules

- **Win:** Reach 1000 points.
- **Lose:** The enemy catches the player before reaching the target score.

## Controls

W – Up  
A – Left  
S – Down  
D – Right

## Unity Version

Unity 6.3 LTS (6000.3.28f1)
